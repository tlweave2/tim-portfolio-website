Work

Oct 2024 to now

VidlyAI

Sole developer

A video editor for clips shot on a phone. You upload raw clips and get back a captioned vertical reel.

A Python worker transcribes the audio with faster-whisper, tracks faces with OpenCV, and estimates who is speaking from mouth movement and a voice fingerprint. Claude then returns an edit decision list, which is checked against the source clips before FFmpeg renders it.

Each reel is stored as that edit list, so changing an edit re-renders the video without transcribing it again or calling the model again.

The API and the worker talk through a PostgreSQL job queue. Deploys go through GitHub Actions and only run if the 331 engine tests pass.

Spring Boot, PostgreSQL, React, Capacitor for iOS and Android, Python, faster-whisper, OpenCV, FFmpeg, Claude API
